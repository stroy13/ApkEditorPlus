С чего начать

  1. На главном экране нажмите Выберите файл APK, чтобы открыть файл из памяти устройства, или Выберите установленный APK, чтобы выбрать приложение из списка.
  2. Найдите нужный APK и подтвердите выбор. Для первого знакомства выберите копию APK, а не единственный оригинал.
  3. Если приложение предлагает режим редактирования, выбирайте его по задаче из следующего раздела. Затем дождитесь окончания чтения APK.

APK — установочный пакет Android. Изменение APK не обновляет исходное приложение автоматически: результат нужно отдельно собрать и установить.

Какой режим выбрать

Общее редактирование · Common Edit

Для простых параметров, которые приложение умеет менять напрямую. Выбирайте его, если нужно изменить только доступные поля, например отображаемое имя.

Простое редактирование · Simple Edit

Замена отдельных файлов внутри APK — например изображения — без полной распаковки и пересборки всех ресурсов. Подойдёт для простой замены файла.

Полное редактирование · Full Edit

Полная обработка ресурсов и содержимого APK с последующей пересборкой. Используйте для строк, изображений и других ресурсов, когда простого режима недостаточно. Этот вариант дольше и требует больше памяти и свободного места.

Редактирование XML · XML File Edit (бета)

Для работы с отдельным XML-файлом. Функция помечена как бета: сохраните исходник и проверьте результат.

Редактирование данных · Edit Data [ROOT]

Работа с данными установленного приложения требует root-доступа. Этот пункт не нужен для обычного редактирования APK.

Первое упражнение: наше приложение

Чтобы примеры соответствовали этой версии, в качестве учебного APK используйте APK Editor Plus — то самое приложение, в котором открыта справка. На главном экране нажмите Выберите установленный APK и найдите в списке APK Editor Plus.

  1. Для простого упражнения выберите Общее редактирование.
  2. Измените только отображаемое название, например добавьте слово «тест», и сохраните результат. Так вы увидите, как создаётся отдельный изменённый APK.
  3. Не устанавливайте полученный файл поверх работающего APK Editor Plus: подпись изменённого файла может отличаться от установленной версии. Сохраните оригинал и используйте результат только как учебную копию.

Это упражнение использует наше приложение вместо сторонней демонстрационной игры. Если APK Editor Plus не появляется в списке, используйте кнопку Выберите файл APK и откройте заранее сохранённую копию APK Editor Plus.

Поменять название или значок

  1. Откройте APK и выберите Общее редактирование, если этот режим доступен.
  2. Измените нужное поле. Для значка используйте подходящее изображение; проверьте, как оно выглядит в разных размерах.
  3. Сохраните изменения и дождитесь сообщения о готовом APK. Не закрывайте приложение во время сборки.

Названия пунктов и доступные поля могут отличаться в зависимости от содержимого выбранного приложения.

Изменить текст или ресурс

  1. Откройте APK в режиме редактирования ресурсов и дождитесь завершения обработки.
  2. Найдите нужный файл в списке ресурсов. Текст интерфейса обычно находится в ресурсах строк; картинки — среди изображений. Названия и структура зависят от APK.
  3. Откройте файл, внесите небольшое изменение и сохраните его. Для XML сохраняйте синтаксис и не удаляйте нужные теги или подстановки.
  4. Соберите APK и проверьте его на устройстве. Если приложение не запускается, отмените последнее изменение или начните заново с исходного APK.

Заменить файл внутри APK

  1. Выберите режим замены файлов.
  2. Укажите файл внутри APK и выберите файл-замену с устройства.
  3. Сверьте имя, формат и назначение. Для изображений также проверьте размеры и варианты для разных экранов.
  4. Сохраните и проверьте собранное приложение. Неподходящий файл может привести к ошибкам или сбою приложения.

Собрать и установить результат

  1. Нажмите кнопку сохранения или сборки на экране редактирования и дождитесь окончания процесса.
  2. Откройте итоговый путь или список последних файлов и убедитесь, что новый APK создан.
  3. Перед установкой сохраните исходный APK. Android может не установить изменённый пакет поверх оригинала, если у них разные подписи. В таком случае удаление оригинала может удалить его данные — сначала сделайте резервную копию и убедитесь, что сможете переустановить исходное приложение.
  4. Устанавливайте APK только если доверяете его содержимому и источнику.

Перевод строк

Если в проекте доступен перевод ресурсов, можно перевести строки на другой язык. Точный результат зависит от исходного текста и выбранного движка.

Локальный ИИ-перевод работает на устройстве и не отправляет строки на сервер. Для него нужно заранее установить модель в настройках; большие модели занимают несколько гигабайт и требуют свободной оперативной памяти. После перевода проверьте строки вручную, особенно имена, кнопки, форматирование и значения в фигурных скобках.

Настройки инструментов

На главном экране нажмите шестерёнку, затем откройте пункт Инструменты и версии. Здесь выбираются вспомогательные средства для сборки и обработки APK. Если не знаете, что выбрать, оставьте значение по умолчанию: экспериментальные инструменты могут быть несовместимы с конкретным устройством или APK.

Важно знать

  • Сначала делайте копию исходного APK и сохраняйте промежуточные результаты.
  • Редактирование не гарантирует, что любой APK удастся собрать или что изменённое приложение будет работать.
  • Большие APK могут требовать много памяти и места. Закройте другие приложения, если устройство испытывает нехватку ресурсов.
  • Не удаляйте разрешения и компоненты, назначение которых вам неизвестно: приложение может перестать работать.
  • Соблюдайте лицензию приложения и права его владельца. Не используйте редактор для обхода защиты, мошенничества или несанкционированного доступа.

Названия команд могут немного различаться в разных версиях приложения. Если не уверены, сначала попробуйте действие на копии APK.
