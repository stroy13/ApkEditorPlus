# Чек-лист перед каждой новой сборкой

Перед запуском Gradle или CI-сборки обязательно:

1. Открыть `apkEditorPlus/build.gradle`.
2. Увеличить `versionCode` минимум на единицу относительно предыдущей сборки.
3. Синхронно обновить `versionName` в формате `1.10.0.<versionCode>`.
4. Добавить верхнюю запись в `docs/CHANGELOG.md` и указать новый versionCode.
5. Обновить актуальную версию в `README.md`.
6. Только после этого запускать тесты и собирать APK.

Это обязательное правило: **перед каждой новой сборкой версию нужно поднимать**.
